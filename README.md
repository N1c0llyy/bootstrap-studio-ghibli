# 🌿 Studio Ghibli

Uma página web inspirada no universo do **Studio Ghibli**, desenvolvida como um projeto de prática em desenvolvimento front-end.

O projeto busca explorar a criação de uma interface visualmente agradável, utilizando elementos inspirados na identidade e na atmosfera dos filmes do estúdio.

## ✨ Demonstração

🔗 **Acesse o projeto:**  
https://bootstrap-studio-ghibli.vercel.app/

## 🖼️ Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar a criação e estruturação de uma página web, trabalhando principalmente com **HTML, CSS e elementos visuais**.

A proposta foi criar uma experiência inspirada no universo do Studio Ghibli, utilizando imagens e uma composição visual que remete à atmosfera característica de suas obras.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap Studio
- Vercel

## 📁 Estrutura do projeto

```text
bootstrap-studio-ghibli/

```

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/N1c0llyy/bootstrap-studio-ghibli.git
```

### 2. Acesse a pasta do projeto

```bash
cd bootstrap-studio-ghibli
```

### 3. Execute o projeto

Como o projeto é composto por arquivos HTML e recursos estáticos, basta abrir o arquivo `index.html` em um navegador.

Também é possível utilizar uma extensão como o **Live Server** no VS Code para executar o projeto localmente.
